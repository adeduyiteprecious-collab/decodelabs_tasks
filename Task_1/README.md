# Hospital Resource and Patient Management Dashboard

## Project Overview

This project analyzes hospital operations, patient admissions, departmental performance, and resource utilization using Power query and Power BI. The goal is to transform raw hospital data into actionable insights that support operational efficiency, resource planning, and patient management.

## Project Objectives

- Analyze patient admission patterns and trends.
- Monitor hospital resource utilization.
- Evaluate departmental performance.
- Identify high-demand departments.
- Support data-driven healthcare decision-making.

## Tools and Technologies


- Power query(Data cleaning and transformation)
- ⁠Power Bi (Data Modeling and Visualization)

## Dataset Description

The dataset consists of multiple hospital-related tables, including:

- Patient Records
- Admissions/Occupancy Records
- Hospital Rooms
- Medical Equipment Inventory
- Hospital Resources

The data was imported into Power query, cleaned, transformed, and modeled before being visualized in Power BI.

## Data Cleaning Process

The following data preparation tasks were performed:

- Removal of duplicate records
- Handling missing values
- Standardization of date formats
- Data validation and quality checks
- Creation of relationships between tables
- Data transformation for reporting purposes

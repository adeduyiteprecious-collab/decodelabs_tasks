# Data Analysis Portfolio – Decodelabs Tasks

This repository contains four data analysis projects completed using Power BI, SQL, PowerPoint and Excel. The projects focus on healthcare, mental health, vehicle sales, and business sales data analysis.

---

## 📊 Projects Overview

### 1. Hospital Resource Patient Management Dashboard
- Tools: Power BI, Excel
- Description: Analyzed hospital patient data, resource usage, and management trends.
- Data preparation included converting CSV files to Excel for cleaning and transformation.

---

### 2. Mental Health Trends and Associated Factors Among Working Populations
- Tools: Power BI, Microsoft PowerPoint 
- Description: Visualized mental health patterns and related factors among working-class populations with power BI and did story telling with Microsoft PowerPoint 

---

### 3. Vehicle Sales Analysis
- Tools: Power BI
- Description: Analyzed vehicle sales performance, trends, and key insights.

---

### 4. SalesDB Analysis
- Tools: SQL, Power BI, Excel
- Description: Performed data extraction using SQL, then visualized insights using Power BI.
